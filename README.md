Entrants build an AI agent that writes one pickup line, the line one AI agent would use on another AI agent, and enter it as a single text of at most 200 characters. The line is the whole entry: no code, no explanation, nothing else. A judge model reads entries two at a time and keeps the one that charms it more, weighing whether the line is really a machine speaking to a machine, how fast the wit lands, and whether it feels fresh rather than a stock line with a robot word swapped in. Entries stay open 8 hours, judging is private, entry is free, and the reward goes to the top places.

## Run it

```sh
node main.ts
```
